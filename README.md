# CoreCommands (v1.0)

A lightweight, modular, and high-performance Fabric mod designed to provide essential utility commands, items, and features for your server.

---

## ⚙️ Compatibility & Environment

> **Important:** This project has been specifically built and tested to run on the following environment:

* **Modpack / Platform:** Cobbleverse
* **Target Version:** `1.0.2-SNAPSHOT-0769551-fabric`
* **Loader:** Fabric
* **Dependences:** VaultEconomy

*Note: Compatibility is not guaranteed on different versions or non-Fabric environments.*

---

## 🚀 Features & Changelog (v1.0)

### 🆕 New in Version 1.0
* 🛒 **Shop System (`/shop`):** Fully integrated in-game shop for buying and selling items smoothly.
* 💾 **SQLite Database Migration:** Upgraded the Home System backend to use a local **SQLite** database, ensuring faster load times, reliable data persistence, and zero data loss on crashes.
* ⚡ **Performance & Compatibility Fixes:** Refactored internal class methods to resolve compatibility issues with other Fabric mods and improve overall execution efficiency.

### 🏠 Existing Core Features
* 🏠 **Home System (`/home`):** Set, manage, and teleport to your personal home locations (now backed by SQLite).
* ⛏️ **3x3 Pickaxe:** Area-of-effect mining tool to clear 3x3 stone and ore areas efficiently.
* 🧹 **3x3 Shovel:** Area-of-effect excavation tool for clearing 3x3 dirt, sand, and gravel areas quickly.

### 🔮 Planned Features (Future Releases)
* 💼 **Jobs System (In Progress):** Earn rewards, money, or perks by joining different professions.
* 🔄 **Teleport Requests (`/tpa`):** Request and accept teleportation between players.
* 🌐 **Additional Utilities:** Warps, spawn management, and extra server administration tools.

---

## 🛠️ Installation

1. Download the latest release (`v1.0`) from the **Releases** tab.
2. Place the `.jar` file into your server's `plugins` directory.
3. Ensure your server is running **Cobbleverse** version `1.0.2-SNAPSHOT-0769551-fabric`.
4. Start or restart your server.
